## 🚀 核心專案介紹 (Featured Projects)

### 1. 📊 大數據海事國考戰略 (Data-Driven Maritime Exam Framework)
利用現代化資料科學思維，我建立了一套「考情落差比對法 (Gap Analysis)」模型，針對長達 10 年的台灣管輪航海特考題庫進行降維打擊：
*   **Macro Heatmaps (大數據雷達)**：全盤掃描題庫，揪出各科配分熱區與投資報酬率 (ROI)。
*   **Syllabus Pruning (課綱除草/差距分析)**：無情比對官方大綱與實際題庫，精準剔除「殭屍考點」，深掘「隱藏魔王單元」。
*   **Micro-Sniper Protocol (深度擊破)**：建立專屬的防呆秒殺表與排故矩陣，將教科書上龐雜的工程條文轉譯為機艙實務 SOP。

*（所有詳細的攻略與分析報表，皆已發佈於 Vlog 的 [海事心得專區](https://vicmeng-jpg.github.io/VIC/maritime-notes-index) 中！）*

### 2. 🕷️ Ship Exam Crawler (海事國考題庫爬蟲)
為了解決傳統輪機員手動頻繁下載考卷的痛苦，我親自用 Python 開發了一套自動化爬蟲工具。
*   **技術棧**: `Python`, `BeautifulSoup`, `Requests`
*   **功能特點**: 具備互動式 CLI 介面、歷史考題批次下載、智能過濾機制，以及防重複下載的防呆機制。
*   **未來計畫**: 即將啟動「模組化重構 (Modular Refactoring)」，將初期的單一腳本升級為符合軟體工程規範的模組化專案。
