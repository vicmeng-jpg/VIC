# 航海職涯發展與適任證書重新生效專案 (Project Seafarer Revalidation)

這是您專屬的「大管輪／船副」職涯戰情室資料夾。為確保未來大量的法規、考題與證件影本不混亂，本助理已將資料夾劃分為四大模組，請嚴格按照以下分類存放檔案：

## 📁 資料夾結構與存放規範

### `01_Admin_換證文件/` （行政組）
- **用途**：放置所有臨櫃辦理與個人身分相關的實體文件電子檔。
- **應存清單**：身分證正反面影本、船員服務手冊掃描檔、體檢表、切結書電子檔、大頭照電子檔等。

### `02_Exam_適任測驗/` （考務組）
- **用途**：存放「適任證書重新生效測驗」的所有備考素材。
- **應存清單**：Python 爬蟲程式 (`crawler.py`)、下載的歷屆考題題庫 (PDF/Word)、刷題筆記、錯題本等。

### `03_STCW_專業訓練/` （受訓組）
- **用途**：追蹤 3 張重新生效小證，以及 4 張無效期小證的受訓與報名資料。
- **應存清單**：高科大報名繳費單據、上課錄取簡訊截圖、受訓結業證書電子檔、MTNet 相關列印單。

### `04_References_法規與手冊/` （法規參謀組）
- **用途**：存放由外界取得的官方公文、規章與參考資料。
- **現有檔案**：
  - `STCW公約2010年修正案專業訓練課程規劃更新案.pdf`
  - `附件一各職級船員依STCW公約2010年修正案應受專業訓練項目.pdf`
