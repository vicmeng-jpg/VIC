# 🛠️ 專案中心 (Projects Hub)

歡迎來到我的技術實驗室。這裡收納了我從「航海實務」中衍生的各類技術專案，涵蓋了自動化爬蟲、數據處理、OCR 以及生活實驗。每一個專案都是我將「工程思維」應用於解決真實問題的紀錄。

---

## 🚀 現有專案清單

### 🕷️ [Ship Exam Crawler](./ship-crawler/index.md)
海事國考題庫自動化下載工具。解決輪機員手動下載考卷的痛點，具備智能命名與防重複機制。

### 📄 [Maritime OCR Pipeline](./maritime-ocr/index.md)
海事知識預處理管線。將大型簡體海事 PDF 轉換為結構化、可檢索的繁體 Markdown 文件，優化 NotebookLM 的分析效率。

### 🧪 [Drink Lab (飲料實驗室)](./drink-lab/index.md)
數據驅動的生活實驗。探索鹽埕奶茶街的風味組合，以結構化報告記錄每一場味蕾實驗。

### ⚓ [Seafarer Revalidation](./seafarer-revalidation/index.md)
一等管輪適任證書重新生效專案。整合所有法規、分析框架與受訓進度，是我的換證戰情室。
