# 🕷️ Ship Exam Crawler (海事試題爬蟲)

這是我為了解決輪機員「手動下載考卷」的痛點而開發的自動化工具。透過這個 Python 程式，可以快速下載歷年的船員評估試題，並自動進行命名與分類。

> [!TIP]
> **為什麼要寫這個工具？**  
> 輪機國考的題庫散落在各個梯次中，傳統方式需要手動點選幾十個連結。透過自動化，我們可以一鍵完成所有科目的蒐集，為 NotebookLM 的大數據分析提供最乾淨的原材料。
